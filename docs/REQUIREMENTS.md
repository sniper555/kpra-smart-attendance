# Requirements

## Confirmed
- Initial user group: authorized KPRA managers.
- Laptop and mobile attendance.
- Responsive web app/PWA.
- Hybrid hosting; public HTTPS access, internal application/backend/database.
- SenseFace 7 Series, supplied device SenseFace 7A.
- Existing TimeNex portal must remain operational.
- Remote and physical attendance must be clearly distinguished.

## MVP
- Individual manager login and MFA.
- Manager Check-In/Check-Out.
- Personal attendance history and monthly summary.
- Admin manager roster and employee PIN mapping.
- Correction request/approval.
- Audit log.
- CSV export.
- PWA.
- Basic health/connection status.

## Not in MVP
- Payroll, leave management, full HRMS.
- Universal ZKTeco support.
- Fake biometric simulator or biometric spoofing.
- Facial/fingerprint template storage.
- Complex analytics.
- Direct production database manipulation.

## Policy items requiring KPRA confirmation
- Which manager roles are eligible.
- Whether remote attendance is authorized.
- Work schedules, grace periods, weekends, holidays.
- Whether location restrictions apply.
- Correction approval authority.
- Retention period and reporting requirements.
